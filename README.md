My research focuses on robotics and autonomous systems, integrating perception, control, and learning to develop safe and reliable robots.

## Selected Robotics Projects

### UAV Swarm Perception

Developed a real-time LiDAR perception and voxel-mapping system on Raspberry Pi 4, distinguishing neighboring UAVs from dynamic obstacles to enable communication-free swarm perception.

For more details, please refer to the ARIS 2026 publication listed above.

### [Multi-UAV Formation Control](https://github.com/en-rong-wang/Multi-UAV-Formation-Control)
Simulation and outdoor experimental validation of coordinated UAV flight.

### [Autonomous Mobile Robot](https://github.com/en-rong-wang/Autonomous-Mobile-Robot)
Developed a ROS 2-based mobile robot integrating autonomous
navigation, obstacle avoidance, and real-time object tracking.

### [Vision-Guided Robot Manipulation](https://github.com/en-rong-wang/Vision-Guided-Robot-Manipulation)
Vision-guided object recognition and robotic grasping using a Techman TM5 collaborative robot.
